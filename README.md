# FamilyHub — Add-on Home Assistant

Application de gestion familiale complète.

## Installation
1. HA → Paramètres → Modules complémentaires → Dépôts
2. Ajouter : `https://github.com/ton-compte/familyhub-addon`
3. Installer FamilyHub → Configurer → Démarrer

## Configuration
```yaml
secret: "mot_de_passe"   # optionnel
```

## Synchronisation
Les données sont sauvegardées automatiquement dans l'add-on HA.
Accès depuis Paramètres → Sync dans l'app.

## Sauvegarde
Paramètres → Système → Sauvegardes dans HA.
